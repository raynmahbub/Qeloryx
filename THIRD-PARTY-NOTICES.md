# Third-Party Notices

Qeloryx is built on Apple platforms (Swift, SwiftUI, AVFoundation,
MediaPlayer, WidgetKit) under their respective Apple licenses.

**Qeloryx currently declares zero external Swift package dependencies and
ships no vendored third-party source files.**

## Reuse policy

When first-party work incorporates third-party material, this file is the
system of record:

1. **Permissive licenses (MIT, BSD, Apache-2.0)** — files keep their
   original copyright header and are listed below. Apache-2.0 grants also
   apply to any such components.
2. **MPL-2.0** — covered files stay under MPL-2.0 (file-level copyleft);
   their modified sources remain publicly available in this repository,
   and they may be combined with first-party proprietary code as a Larger
   Work per MPL-2.0 §1.14/§3.
3. **Copyleft or restricted licenses (GPL-family, source-available EULAs)** —
   **no code is copied, ever.** Features inspired by such projects are
   written independently from public behavior specifications; the resulting
   first-party file records its independent origin. Standard algorithms
   (for example, ReplayGain) are implemented from their public
   specifications, not from any project's source.

## Current components
