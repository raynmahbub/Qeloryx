# Qeloryx Architecture

This document describes the redesigned repository layout and how every file in
the previous layout maps to it. The design is unchanged in spirit: an
offline-first iOS music player with a portable domain core, a SwiftUI shell,
and thin platform adapters — dependencies point inward, and nothing constructs
its own engine.

## Intentional deviations & notes

1. **Type names vs file names.** `Astryx*` domain type names are kept inside the
   files (e.g. `AstryxTrack` in `Models/Music/Track.swift`). Renaming 150+ types
   would be churn without behavior change. Only the feature-facing public types
   were renamed to the new architecture's vocabulary (see rename list above).
2. **Feature copy.** User-facing strings that are product names ("Time Capsule"
   inside the Statistics screen, capability names like "Astryx Spaces") were kept;
   screens were renamed, campaigns were not.
3. **New files** were added only where the target architecture calls for a home
   or a screen: `AppDelegate`, `AppLifecycle`, `AppCompositionRoot`,
   `Localizable.xcstrings`, `Views/Queue` + `QueueViewModel`, `Views/Settings` +
   `SettingsViewModel`, placeholder `Views/Components/*`, and small honest
   facades (`FavoritesService`, `ListeningHistoryService`, `NowPlayingCoordinator`,
   `CredentialStore` (in-memory only — keychain is the designated production
   adapter), `SyncService`/`SocialService` no-op defaults).
4. **`Services/Audio/`** is intentionally empty (`.gitkeep`): portable audio
   session and DSP code paths are `Services/Player` and `Services/DSP`;
   framework audio adapters are `Platform/Audio`. Nothing portable was invented
   for the folder.
5. **Placeholder defaults refuse honestly.** The no-provider `SyncService` and
   `SocialService` throw `.noProviderConfigured` / `.unavailable`; the
   credential store is documented as previews/tests only.
6. **`Qeloryx.xcodeproj`** remains generated (gitignored). `project.yml` +
   `Configuration/*.xcconfig` are the source of truth.
7. Historical docs (`Docs/ADR`, `Docs/EPL`, `Docs/IL`, `Docs/SHM`, `Docs/ACC`,
   `Docs/MASTER_AUDIT`) keep their original path references as a record of the
   layout at the time they were written. Operational docs (README, BUILD_READINESS,
   BRANDING, RELEASE_FLOW) were updated.
8. **`QeloryxUITests`** asserts launch invariants only; it does not fabricate
   playback. A real playback UI test needs fixture audio in the app bundle.

## Build

```sh
swift build            # SPM: QeloryxCore + QeloryxDesignSystem + QeloryxPlatform
swift test             # QeloryxTests (categorized)
xcodegen generate      # app + QeloryxTests + QeloryxUITests
```

`QeloryxCore` = `Qeloryx/Models` + `Qeloryx/Services` + `Qeloryx/Utilities`
(excluding the SwiftUI environment glue). The XcodeGen app target compiles all
of `Qeloryx/` as a single module, as before.
